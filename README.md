The project contains 4 main files, which can be found under the src folder.

1. GameEngine.kt: The core logic of the Connect 4 game
2. Main.kt: The main code for the website UI
3. index.html: The HTML code for the website
4. GameLogicTest.kt: Unit tests specifically for the core logic of the game

The website scales according to screen size while maintaining a consistent appearance.
